# iosApp — Setup Instructions

The Swift sources and config files are ready. The `iosApp.xcodeproj/project.pbxproj`
is a stub placeholder (generating a valid pbxproj by hand is error-prone; Xcode does it
reliably in seconds). Follow the steps below once to wire everything up.

## One-time Xcode setup

1. Open Xcode and choose **File → New → Project**.
2. Select **iOS → App**, click Next.
3. Fill in:
   - Product Name: `iosApp`
   - Bundle Identifier: `eu.eurostat.app`
   - Interface: SwiftUI
   - Language: Swift
   - Deployment Target: iOS 15.0
4. When asked where to save, choose the **`iosApp/`** folder inside the repo root
   (so the project lands at `iosApp/iosApp.xcodeproj`). This overwrites the stub pbxproj.
5. Delete the auto-generated `ContentView.swift` and `iOSApp.swift` stubs Xcode created.
6. In the Project navigator, right-click the `iosApp` group and choose
   **Add Files to "iosApp"…**, then add the existing files:
   - `iosApp/iosApp/iOSApp.swift`
   - `iosApp/iosApp/ContentView.swift`
   - `iosApp/iosApp/Info.plist`
7. Add `iosApp/Configuration/Config.xcconfig` to the project (drag it in or use
   Add Files). In **Project → Info → Configurations**, set both Debug and Release
   to use `Config`.

## Add the KMP Gradle build phase

In the target's **Build Phases** tab, add a **New Run Script Phase** and drag it
**above** the "Compile Sources" phase. Set:

- Shell: `/bin/sh`
- Script body:
  ```sh
  cd "$SRCROOT/.." && ./gradlew :composeApp:embedAndSignAppleFrameworkForXcode
  ```
- Uncheck "Based on dependency analysis" so it always runs.

## Add Framework Search Paths

In **Build Settings → Framework Search Paths** add (for both Debug and Release):

```
$(SRCROOT)/../composeApp/build/xcode-frameworks/$(CONFIGURATION)/$(SDK_NAME)
```

## Link ComposeApp.framework

In **Build Phases → Link Binary With Libraries**, click `+` and add
`ComposeApp.framework` from the path above. Set it to **Embed & Sign**.

## Build and run

After completing the steps above, select an iOS Simulator and press **Run** (⌘R).
Gradle will build the KMP framework first, then Xcode will compile the Swift layer.

## File layout

```
iosApp/
├── Configuration/
│   └── Config.xcconfig        # BUNDLE_ID, APP_NAME, TEAM_ID
├── iosApp/
│   ├── iOSApp.swift           # @main entry — calls initKoinIos()
│   ├── ContentView.swift      # Minimal SwiftUI view
│   └── Info.plist             # Standard iOS app plist
└── iosApp.xcodeproj/          # Generated by Xcode (stub placeholder currently)
    └── project.pbxproj
```
