EU Stats Multiplatform — це незалежний клієнт із відкритим кодом для публічного API Eurostat. Він перетворює щільні відповіді JSON-stat 2.0, які публікує Європейське статистичне бюро, на спокійні, читабельні графіки.

Вісім тематичних модулів охоплюють дані, що цікавлять громадян і журналістів найбільше:

• Економіка — ВВП, гармонізована інфляція (HICP) і державний дефіцит у % ВВП
• Населення — демографічні піраміди для 18 п'ятирічних вікових когорт
• Довкілля — викиди парникових газів, кінцеве споживання енергії та кліматичний індекс SDG-13
• Торгівля — внутрішньо-ЄС експорт, імпорт і торговельний баланс
• Транспорт — пасажиропотік автомобільного й авіаційного транспорту поруч
• Туризм — внутрішні, іноземні та сумарні ночівлі плюс місячна теплова мапа сезонності
• Соціальна сфера — ризик бідності, соціальне виключення та самооцінка здоров'я
• Наука — R&D як % ВВП, користування інтернетом і вища освіта

Чим EU Stats відрізняється:

• Без облікових записів, без аналітики, без трекінгу, без реклами
• Працює офлайн — останній перегляд залишається доступним без мережі
• Відкриті дані, відкритий код — ліцензія AGPL-3.0
• Один кодовий простір, три форм-фактори — телефон, планшет, ПК
• Створено для спокійного читання — типографіка та кольори підібрані для тривалих сесій

Застосунок не пов'язаний із Eurostat або Європейською Комісією, не спонсорується та не сертифікується ними. Назва «Eurostat» вживається виключно для посилання на публічне джерело даних. Дані публікуються так, як їх оприлюднює Eurostat, на ліцензії Creative Commons Attribution 4.0.
